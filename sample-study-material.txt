Computer Networks - Revision Notes

OSI Model
The Open Systems Interconnection (OSI) model organizes network communication into seven layers.

1. Physical: Sends raw bits over a physical medium such as copper, fiber, or radio.
2. Data Link: Transfers frames between directly connected devices and uses MAC addresses.
3. Network: Routes packets between networks using logical addresses such as IP addresses.
4. Transport: Provides end-to-end communication. TCP is connection-oriented and reliable; UDP is connectionless and has lower overhead.
5. Session: Establishes, manages, and ends communication sessions.
6. Presentation: Handles data representation, translation, compression, and encryption.
7. Application: Provides network services to applications, such as HTTP, DNS, and SMTP.

Encapsulation
When data is sent, each lower network layer adds its own control information. At the receiving end, the layers remove and interpret that information in reverse order. The transport layer works with segments, the network layer with packets, the data-link layer with frames, and the physical layer transmits bits.

Quick Review
- Which OSI layer routes IP packets? Network layer (Layer 3).
- Which transport protocol provides reliable, ordered delivery? TCP.
- What is the data-link protocol data unit? A frame.
- Which layer commonly provides HTTP and DNS services? Application layer (Layer 7).
